\begin{abstract}
    \large
    We hypothesized that there would be some correlation between gendered—based on the APA's list of gendered terms—language
    and industry advertisements, and how that sentiment changes over time. Through analysis of job
    advertisements 2004-2015 
    (\href{https://www.kaggle.com/datasets/madhab/jobposts/data}{Online Job Postings}) 
    and 2023-2024 
    (\href{https://www.kaggle.com/datasets/madhab/jobposts/data}{LinkedIn Job Postings (2023 - 2024})
    ), pulled from free open source data on Kaggle. Through analysis of this data, we have 
    concluded that there is a relationship between both job industry, gendered language in job
    advertizements and that this has varied over time. For this paper we used the R programming language
    in conjunction with the Tidyverse library as we have previous experience using those in a linguistic context.
    Possible further explorations could examine
    more historical data. 
\end{abstract}
